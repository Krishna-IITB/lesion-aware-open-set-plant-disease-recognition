# Contributing

Open an issue before changing the research protocol or taxonomy. Small bug fixes should include a
regression test. Method changes must state the hypothesis, affected configuration, leakage analysis,
and expected artifact changes.

Install the development environment from the README and run the complete verification commands in
`AGENTS.md`. Do not submit generated datasets, weights, caches, checkpoints, or unreviewed metrics.
Any results table change must point to immutable run metadata and distinguish paper-reported,
reproduced, and extension measurements.
