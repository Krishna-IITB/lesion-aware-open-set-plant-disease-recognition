## Historical project story

- Extended an MVPDR-style baseline with frozen DINOv3 lesion features and a PlantSeg-supervised
  decoder.
- Designed three-view gated fusion across textual, global and lesion prototypes using **0.8%
  trainable parameters**.
- Achieved **0.76 mean binary-lesion Dice** for lesion localization.
- Achieved **67% 20-shot lab-to-field macro-F1**, **+6 pp vs same-split MVPDR reproduction**.
- Added open-set abstention with **0.90 AUROC and 40% FPR95** on held-out disease classes.

These values are author-supplied historical results from the December 2025–January 2026 project.
Synthetic smoke metrics, paper-reported numbers, and planned experiments cannot support additional
résumé claims.

## Result provenance categories

The project recognizes three distinct first-party result sources: an author-supplied historical
result from the December 2025–January 2026 project, a result independently reproduced by this
repository, and a new result generated by this repository. Historical values may be presented
naturally in public tables after the author explicitly supplies them, while the results or
reproducibility record retains this concise provenance distinction. The supplied values are
consolidated in `results/README.md`. Never infer an unprovided metric or relabel a historical value
as independently reproduced.
